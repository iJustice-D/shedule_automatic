# Система расписания колледжа

Практический MVP для диссертационного проекта: генерация, редактирование, проверка конфликтов и экспорт расписания колледжа на Python.

Приложение использует:

- реальную учебную нагрузку из `data/Оқу жоспар_ЕТБ-1124.xls`
- реальный учебный процесс из `data/Үрдіс 2025-2026 оқу жылы соңғысы (1).pdf`
- реальный лист недельной нагрузки и закрепления преподавателей из `data/2025-2026 ПРОГРАММИСТТЕР_ИНКАР (1) (2) (1).docx`
- демонстрационные группы, преподавателей, аудитории и предметы

Интерфейс приложения по умолчанию русскоязычный. Для будущего расширения добавлена простая i18n-структура с заготовкой под казахский язык.

## Что изменено в этой версии

- Весь UI переведен на русский язык.
- Добавлена локализация через `app/ui/i18n/`.
- Введены реальные фиксированные пары колледжа:
  - 1 пара: `08:00-09:20`
  - 2 пара: `09:40-11:00`
  - 3 пара: `11:10-12:30`
  - 4 пара: `13:30-14:50`
  - 5 пара: `15:10-16:30`
  - 6 пара: `16:40-18:00`
- Добавлены смены:
  - утренняя: пары `1-3`
  - послеобеденная: пары `4-6`
- Для групп добавлены поля `shift` и `year`.
- Для предметов добавлены `can_be_online` и `default_delivery_mode`.
- Для записей расписания добавлены `delivery_mode`, `shift`, `start_time`, `end_time`.
- Добавлена политика онлайн-занятий по курсу, группе и предмету.
- Онлайн-занятия вынесены в отдельный слой `online_extra`:
  - не занимают обычные пары `1-6`
  - доступны только в среду, четверг и пятницу
  - показываются отдельным блоком в UI и экспортах
- Генератор теперь учитывает:
  - нормализованную недельную нагрузку из DOCX как приоритетный источник
  - состояния закрепления преподавателей: `fixed / multi_teacher / vacancy / unresolved`
  - подгруппы `A/B`
  - teacher no-overlap как главный hard constraint
  - смену группы
  - онлайн-цели по неделе
  - отсутствие аудитории для онлайн-занятий
  - валидацию входных данных перед генерацией
  - локальный ремонт неразмещенных занятий
  - явные конфликты по неразмещенной нагрузке
- В `Учебной нагрузке` появился импорт недельной нагрузки из DOCX, просмотр нормализованных строк, блок вакансий/неразрешённых строк и отчет по балансу преподавателей между семестрами.
- Онлайн-слоты теперь настраиваются в UI как реальные записи с днем и временем, а не только как подписи.
- В редакторе добавлен фильтр преподавателей с вариантом `Все`.
- В режиме просмотра по группе показываются только пары, доступные для смены выбранной группы.
- Конфликты и предложения переведены на русский язык.
- Экспорт в XLSX/PDF/DOCX теперь использует русские заголовки и показывает смену, время пары и формат занятия.
- Добавлены ручные формы для групп, предметов и учебной нагрузки прямо из UI.
- Ручная нагрузка хранится вместе с импортированной, помечается источником и используется генератором наравне с импортом.
- На странице конфликтов ИИ-пояснения теперь открываются в читаемом диалоге, а не в коротких всплывающих уведомлениях.
- PDF-экспорт использует встроенный Unicode-шрифт для корректного вывода кириллицы и казахских символов.
- В редакторе ячейки расписания показывают недели, различают чередование недель и реальные пересечения, а карточки занятий стали читаемее.

## Основные бизнес-правила

- Для обычного расписания используются только учебные недели.
- Практика, экзамены, итоговая аттестация и каникулы блокируются.
- Недельная нагрузка из DOCX делится на:
  - обычную
  - факультативную
  - учебную практику
  - производственную практику
  - строки подгрупп
- Практика и факультативы не принудительно смешиваются с обычной сеткой пар.
- Утренние группы получают занятия только на парах `1-3`.
- Послеобеденные группы получают занятия только на парах `4-6`.
- Онлайн-занятия идут отдельно от обычной сетки, занимают слот у группы и преподавателя, но не требуют аудитории.
- Онлайн-занятия доступны только в среду, четверг и пятницу в отдельных онлайн-слотах.
- Для 2 и 3 курса целевое значение по умолчанию: `3` онлайн-занятия в неделю.
- Для 1 курса онлайн-режим разрешается только для выбранных общих предметов.

## Реальные данные ETB-1124-1

Для группы `ETB-1124-1` в MVP заложены следующие периоды:

- 3 семестр: учебные недели `1-8`
- 4 семестр: учебные недели `23-28` и `39-40`
- Остальные недели семестров размечены как недоступные для обычных занятий

Если PDF в будущем изменит структуру и автоматический разбор станет нестабильным, периоды можно исправить вручную через страницу учебного календаря.

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python seed_demo_data.py
python -m app.main
```

После запуска откройте [http://127.0.0.1:8080](http://127.0.0.1:8080).

### Ручной ввод из UI

- На странице `Группы` доступны действия `Добавить группу`, `Редактировать группу`, `Удалить`.
- На странице `Предметы` доступны действия `Добавить предмет`, `Редактировать предмет`, `Удалить`.
- На странице `Учебная нагрузка` доступны действия `Добавить нагрузку`, `Редактировать нагрузку`, `Удалить`.
- Там же доступен импорт недельной нагрузки из DOCX с последующим просмотром нормализованных строк, вакансий и баланса преподавателей.
- Для нагрузки можно вручную указать группу, предмет, семестр, часы, недели, часов в неделю, пар в неделю, тип занятия, формат проведения и примечание.
- Кнопка `Рассчитать` и переключатель `Авторасчёт` пересчитывают недельную нагрузку из общего количества часов и учебных недель.

## ИИ-пояснения

- Приложение полностью работает без API-ключа.
- `DummyExplanationProvider` используется по умолчанию.
- `GeminiExplanationProvider` оставлен как опциональный провайдер пояснений.
- ИИ не валидирует расписание и не принимает решений о корректности.
